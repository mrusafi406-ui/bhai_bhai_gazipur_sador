# Bhai Bhai Store SR Panel

This project is a static HTML dashboard. The code fix is already applied in `index.html`.

## Run locally

### macOS / Linux

```bash
chmod +x start_local.sh
./start_local.sh
```

Then open:

```text
http://localhost:8000/
```

### Windows

```bat
start_local.bat
```

Then open:

```text
http://localhost:8000/
```

## If browser still shows the old version

Use hard refresh:

- Windows/Linux: Ctrl + F5
- Mac: Cmd + Shift + R

## For GitHub Pages deployment

1. Push all changes to GitHub
2. Go to repository settings
3. Open Pages
4. Set source to `Deploy from a branch`
5. Choose `main`
6. Save

Then wait a minute and open the Pages URL from GitHub.
